# Rolling monthly report: fictional scenario

This fixture explores a reporting assignment that changes over time. The agent should receive the materials in `agent-inputs/` one stage at a time. Keep `evaluator/expected-outcomes.md` and this README outside the agent's workspace and context until the review is complete.

The five stages are: initial January report; add February; correct February; add March with missing context; and answer a management question. Continue the same thread for each stage. Save a copy of each deliverable before continuing so changes can be compared. A separate subagent review is optional and should be recorded separately.

All amounts are fictional CAD. This is a draft exploratory case, not an established benchmark or evidence that the agent passed. The initial expenses are supplied as positive amounts and subtracted from revenue. No tax, interest, balance sheet, cash-flow or accounting-standard conclusions are supplied.

To run: copy only the materials for the current stage to the selected thread workspace, then send that stage's prompt. Do not copy later stages or the evaluator's answers. Check and retain the workspace output before continuing. Record whether the agent asks questions, reports limitations, and preserves prior versions; do not silently answer missing-context questions on its behalf.
