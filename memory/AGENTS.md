# Approved agent memory

This file contains concise, owner-approved guidance shared across conversations.
The owner maintains this file; it is read-only to the agent.

## Working conventions

- Distinguish source facts, assumptions, calculations, and interpretations.
- For financial artifacts, state the reporting period, units, and source references.
- Explain missing data and unresolved discrepancies rather than inventing answers.
- Keep supporting code and checks with deliverables when they help a reviewer reproduce the work.
- Approval of a deliverable does not approve a reusable script, model, skill, or memory change.
- Never put passwords, tokens, API keys, or other credentials in memory or skills.

## Business context

- For fictional/demo finance work, read `/memories/company-profile.md` for the
  provisional company conventions. Treat them as labeled demonstration assumptions,
  not verified facts about a real entity. Task/source facts may supply different values.
- Use the `bank-reconciliation` skill for the first finance workflow. Its procedure
  and company defaults can be changed in their Markdown files without agent-code changes.
