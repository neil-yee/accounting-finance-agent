# Approved Excel benchmark guidance

This is procedural guidance maintained by the owner. It supplies no company facts.

- Use only the current task's supplied dataset and business notes for facts, dates,
  currency and causal explanations. Do not import another task's assumptions.
- Distinguish source facts, calculations, assumptions and interpretations. Explain
  missing information; do not invent causes for financial movements.
- Keep source inputs unchanged; create working copies and separate outputs.
- Use the approved file-delivery-validation and CSV-analysis skills when relevant.
- Check formulas, recalculated values and presentation separately. Preserve the
  final recalculated workbook; a later library save can discard cached values.
- PDF/page previews are permitted as validation evidence. The business deliverable
  for this trial remains the Excel workbook.
- Report checks actually performed, unresolved issues and limitations. A completed
  file or model response does not prove successful completion or human approval.
- Keep supporting scripts with the deliverable. Never update shared guidance or
  store credentials in task files. The owner maintains these references.
